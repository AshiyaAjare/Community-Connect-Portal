Community Platform

A Ruby on Rails-powered platform for building an interactive community within a software company. This application supports both technical and non-technical collaboration, allowing users to engage in threaded conversations inspired by Twitter's reply and retweet functionality.

Features (Planned and In Progress)
- Messages: Create and manage messages with threaded replies.
- User Accounts: Users can post messages and interact with others.
- Conversations: Messages can have parent-child relationships to support discussions and retweet-like functionality.
- PostgreSQL Database: Robust data storage for users and messages.
- RESTful API (Planned): To enable integration with external systems.
